#### 2.2.2 SKU生成算法（笛卡尔积）
**文件位置**: [product.js#L27-47](file:///d:/workspace/BBB/trae0410/trae0410_19/trae0410-GLM/e-commerce-admin/src/stores/product.js#L27-L47)

```javascript
function generateSKUs(specs, basePrice, baseStock) {
  if (!specs || specs.length === 0) {
    return [{
      id: generateId(),
      specs: {},
      price: basePrice,
      stock: baseStock,
      sku: 'DEFAULT'
    }]
  }

  const specValues = specs.map(s => s.values)
  const combinations = specValues.reduce((acc, values) => {
    return acc.flatMap(accItem => 
      values.map(v => [...accItem, v])
    )
  }, [[]])

  return combinations.map((combo, index) => {
    const specObj = {}
    specs.forEach((spec, i) => {
      specObj[spec.name] = combo[i]
    })
    return {
      id: generateId(),
      specs: specObj,
      price: basePrice + (index * 10),
      stock: Math.max(0, baseStock - (index * 5)),
      sku: Object.values(specObj).join('-')
    }
  })
}
```

**算法解析**:
1. **空规格处理**: 无规格时生成默认SKU
2. **笛卡尔积计算**: 使用 `reduce + flatMap` 实现多维组合
3. **SKU编码生成**: 规格值用 `-` 连接（如：`深空黑-256GB`）
4. **价格梯度**: 每个SKU价格递增10元（可自定义策略）
5. **库存递减**: 每个SKU库存递减5件（模拟差异化库存）

**生成示例**:
```
输入规格:
  颜色: ['白色', '黑色']
  尺码: ['S', 'M', 'L']

输出SKU (2 × 3 = 6个):
  ┌─────────────┬──────────┬────────┐
  │ SKU编码      │ 价格      │ 库存   │
  ├─────────────┼──────────┼────────┤
  │ 白色-S      │ basePrice │ 100   │
  │ 白色-M      │ +10      │ 95    │
  │ 白色-L      │ +20      │ 90    │
  │ 黑色-S      │ +30      │ 85    │
  │ 黑色-M      │ +40      │ 80    │
  │ 黑色-L      │ +50      │ 75    │
  └─────────────┴──────────┴────────┘
```

  if (isEdit.value) {
    const product = productStore.getProductById(route.params.id)
    if (product) {
      Object.assign(formData, JSON.parse(JSON.stringify(product)))

**注意**: 使用 `JSON.parse(JSON.stringify())` 实现深拷贝，避免直接修改Store中的数据。

### 4.4 提交流程
```javascript
async function handleSubmit() {
  try {
    await formRef.value.validate()
    
    // 无规格时生成默认SKU
    if (formData.skus.length === 0) {
      formData.skus = productStore.generateSKUs([], formData.basePrice, 100)
    }

    submitting.value = true

    if (isEdit.value) {
      productStore.updateProduct(route.params.id, formData)
      ElMessage.success('修改成功')
    } else {
      productStore.addProduct(formData)
      ElMessage.success('添加成功')
    }

    router.push('/product')
  } catch (error) {
    console.error('Validation failed:', error)
  } finally {
    submitting.value = false
  }
}
```

### 5.1 Composition API 最佳实践
- 使用 `ref`/`reactive` 管理响应式状态
- 使用 `computed` 实现派生状态（如 `isEdit`、`canGenerateSku`、`skuCount`）

## 六、复杂度总结

### 6.1 时间复杂度分析

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 商品列表查询 | O(n) | 遍历过滤商品列表 |
| SKU生成 | O(∏m_i) | m_i为第i个规格的值数量，笛卡尔积 |
| 库存预警计算 | O(n×m) | n个商品，m个SKU |
| 分页查询 | O(1) | 数组切片操作 |

| 模块 | 圈复杂度 | 评估 |
